## Things I've Built

### WebStrike

**AI-Powered Phishing Detection System**

WebStrike is a machine learning-based security solution designed to identify phishing attempts across emails and URLs. By analyzing indicators commonly associated with phishing campaigns, the system helps distinguish malicious content from legitimate communications and supports early threat detection.

**Key Features**

* Analysis of email and URL-based phishing indicators
* Detection of suspicious domains and malicious URL patterns
* Feature extraction from large-scale phishing datasets
* Machine learning-driven classification of phishing attempts
* Improved understanding of phishing behaviors and attack patterns

---

### DeepShield

**Deepfake and Synthetic Media Detection System**

DeepShield focuses on identifying manipulated visual content, including deepfake videos and AI-generated images. By analyzing patterns, inconsistencies, and artifacts commonly found in synthetic media, the system helps distinguish authentic content from manipulated media.

**Key Features**

* Detection of manipulated videos and images
* Identification of AI-generated visual content
* Analysis of facial and visual anomalies
* Fast and scalable detection pipeline
* Accuracy-focused design with reduced false positives

### ATT&CK Navigator

**MITRE ATT&CK-Based Attack Simulation and Detection Platform**

ATT&CK Navigator is a cybersecurity platform that brings offensive and defensive security workflows together. It enables attack simulations mapped to the MITRE ATT&CK framework while providing visibility into detection capabilities and response effectiveness.

**Key Features**

* ATT&CK-mapped attack simulation scenarios
* Security monitoring and telemetry analysis
* Detection coverage assessment
* Attack timeline visualization
* Red Team and Blue Team collaboration workflows

### TeerthFlow

**Smart Crowd Management for Large-Scale Pilgrimages**

TeerthFlow is designed to help manage large gatherings during religious pilgrimages by providing better visibility into crowd movement and congestion. The platform combines monitoring, route optimization, and decision-support features to help authorities maintain safer and more organized events.

**Key Features**

* Real-time crowd monitoring and density analysis
* Intelligent route recommendations to ease congestion
* Centralized dashboard for crowd management
* Risk detection and alert generation
* Secure and privacy-aware data processing
